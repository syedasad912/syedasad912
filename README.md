## 👨‍💻 About Me

I build **multi-tenant .NET backends** and **native Android apps** — mostly for donation and
field-operations platforms, where correctness matters more than novelty.

- 🔭 Currently working on a **.NET / ABP Framework** ERP backend and its **Kotlin** Android client
- 🧱 I care about layered DDD: business rules in the domain, thin application services, honest boundaries
- 🔐 Identity work with **Keycloak** — user migration, custom themes, SSO integration
- 📱 On Android: Compose, Hilt, Room, coroutines/Flow, unidirectional state, lifecycle-correct code
- 🤖 Exploring **agentic development workflows** — using AI as a real part of the SDLC, with CI gates that keep it honest
- 💬 Ask me about ABP's unit-of-work model, multi-tenant data filters, or why `!!` in Kotlin is usually a bug
